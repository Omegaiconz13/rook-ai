Rook, drawn

A paper trading desk for one trade at a time. The chart, the written rules and the journal are read by Ninth; plain TypeScript decides whether a trade is allowed; every decision, including every refusal, is journaled. Six diagrams of the same system at six different scales.

d1The layer rule, as a matrix

Rows are the importing layer, columns the imported one. Everything below the diagonal is legal and is what the code already does; everything above it is a bug waiting for a build failure. One specific cell above the diagonal matters most: agent → adapters, which would make the harness own a transport.

d2Topology: what runs where, and what remembers

Three tiers. The browser owns state and decisions; the edge owns the key and the wire; the model is optional at every layer. There is no database, and that is a design position, not an omission.

d3The desk loop, with the branch that defines the product

Nine steps, one decision, and a refusal path that is as designed as the success path. The gate reads a plan and returns a verdict; it cannot see the chat, the chart or the user's mood.

d4One turn of Ninth, with its budgets

A deterministic router decides what the turn is about before a token is spent. The loop is ours, bounded, and accepts a fake model — which is how 445 tests run without a network.

d5Routing: three maps that must agree

URLs, HTTP routes and intent. They share one vocabulary: desk, gate, journal, ticket, setup. A user should be able to guess an API path from a page name.

d6Plan and ticket: the two state machines

A plan is a proposal. A ticket is a promise. They move separately, and the only transition between them is a human confirmation that a verdict still supports.
